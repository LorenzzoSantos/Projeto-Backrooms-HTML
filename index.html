A LENDA DE PEDRO ERLY

Dizem nos fóruns mais obscuros da Deep Web que Pedro Erly não é apenas um programador, mas sim uma entidade digital. Ele supostamente aprendeu HTML antes mesmo da internet discada existir, codificando seu primeiro site no painel de um microondas usando apenas os bipes de 30 segundos. Ele é o verdadeiro mestre do front-end. Pedro nunca precisou usar display: flex; ou margin: auto; — os elementos da tela simplesmente se alinham no centro por puro respeito e pavor quando ele encara o monitor.

* Os grandes feitos do mito:

* O Rei do CSS: Ele uma vez centralizou uma div usando telepatia, sem encostar no teclado.

* Segurança Máxima: Aquela mensagem "Bota tua senha lixo" no seu formulário? Foi inspirada nele. Para Pedro Erly, qualquer criptografia militar é "lixo", pois ele consegue invadir bancos de dados usando apenas uma calculadora de padaria e um cabo de rede mastigado.

* O Easter Egg: A lenda conta que se você apertar F12 no seu site, for na aba Console e digitar o nome dele três vezes meia-noite, todos os seus bugs de JavaScript desaparecem na mesma hora.
